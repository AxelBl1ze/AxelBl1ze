Junior QA Engineer с **4 месяцами коммерческого опыта** тестирования веб-приложений.

Провожу функциональное, регрессионное, smoke- и интеграционное тестирование.  
Работаю с **REST API, SQL, DevTools и Apache JMeter**, составляю тестовую документацию и оформляю баг-репорты.

Развиваюсь в направлении автоматизации тестирования на **Python**.
